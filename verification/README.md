# yapcasia.org 静的サイト コンテンツ同一性 検証レポート

現行 yapcasia.org（本リポジトリを GitHub Pages で配信）と旧サーバーのコンテンツが
同一に保たれているかを検証した結果をまとめる。判定基準は「URL の完全一致」ではなく
「同じリンク先から同じコンテンツが取得できること」を優先した。

- 生成日: 2026-09-10
- 対象: 2009〜2015 の全ページ（HTML 1,266 ファイル / 内部リンク・アセット参照 約 60,000 件）
- 併記データ: `url-gaps.csv`（現行で 404 になる旧 URL 221 件の分類一覧）

---

## 0. 結論（サマリ）

- **既存ページの内容は高い忠実度で保たれている。** 各年トップや個別ページの本文テキストを
  旧内容と比較したところ大半が完全一致（類似度 1.00）で、静的化に伴う変更（動的部品の除去、
  http→https 化など）以外の本文差異はほとんど無い。**2011 年のみ差異が大きい。**
- **URL カバレッジは約 87%。** 旧サイトが 200 を返していた 1,724 URL のうち、現行で
  そのまま取得できるのは 1,503 件（200 が 1,491、恒久リダイレクトで有効が 12）。
  残り **221 件が現行では 404**。
- 221 件の 404 の内訳は下表のとおりで、**大半は「想定内」または「許容範囲」**（動的機能の廃止、
  URL 変更だが内容は別パスに存在、応募/不採択トーク等の孤立 URL）。
  **実質的に要対応と考えられるのは概ね 30〜35 件**（2013 年スピーカー個別ページのリンク切れ、
  2010/2011 の一部ニュース、individual_sponsors 等）。

---

## 1. 検証方法と重要な制約

### 重要な制約: 旧サーバーへ直接アクセスできなかった

指示の `curl --resolve yapcasia.org:80:133.242.211.35 ...` は、本実行環境の外向き
プロキシが **Host ヘッダを再解決する** ため機能しなかった。`Host: yapcasia.org` を付けた
リクエストは常に Cloudflare（＝現行サイト）へ転送され、旧サーバーの yapcasia vhost には届かない。
旧 IP 133.242.211.35 自体は到達可能だが、既定 vhost が **perldoc.jp** に変わっており
`/2015/` 等は 404 を返す（`Host: yapcasia.org` を送ると再解決で Cloudflare に飛ぶ）。

- 直接 TCP 接続（プロキシ回避）でも Host ベースで透過的に再解決され、同じ結果になることを確認。
- したがって「稼働中の旧サーバー」との突き合わせは本環境では不可能。

### 代替リファレンス: Wayback Machine

旧サイトの内容・URL 一覧の参照元として **Wayback Machine（web.archive.org, HTTPS）** を使用した。
CDX API とスナップショット取得（`id_` raw）はいずれも到達可能。
- 旧 URL 一覧: CDX から yapcasia.org/{年} の `statuscode:200` かつ `text/html` を年別に取得し、
  urlkey で重複排除（計 1,789 URL、トラッキングパラメータ正規化後 1,724）。
- 内容比較: 会期当時（各年）の raw スナップショットと現行リポジトリのファイルをテキスト比較。

**注意**: Wayback は「稼働中の旧サーバーの現在の状態」そのものではなく、過去スナップショットの集合。
過去に存在したが後に旧サーバーからも削除された URL（不採択トークのページ等）を含み得る。
本レポートの「差分」を最終確定するには、旧サーバーへ到達できる環境での再突き合わせが望ましい
（下記コマンドが使える環境なら実行可能）。

```
curl --resolve yapcasia.org:80:133.242.211.35 http://yapcasia.org/2013/member/show/<UUID>
```

### 現行サイトの配信挙動（判定に必要な前提）

現行 yapcasia.org は GitHub Pages の前段に Cloudflare があり、クエリ付き URL を
`path?key=val` → `path@key=val.html` に書き換えて配信している（該当ファイルがある時のみ 200）。
例: `/2013/talk/schedule?date=2013-09-19` は `schedule@date=2013-09-19.html` を返す。
このためリンク到達性の判定は、ファイルシステムだけでなく **実サイトへの HTTP プローブ** で行った。

## 2. コンテンツ同一性（既存ページの忠実度）

旧（Wayback 会期当時）と現行の本文テキスト（タグ・スクリプト除去後）を比較した代表サンプル:

| ページ | 類似度 |
|---|---|
| /2010/, /2012/, /2013/, /2014/, /2015/ 各トップ | 1.00 |
| /2012・2014 talk/show（個別トーク） | 1.00 |
| /2012 news、/2013・2014 news 一覧 | 1.00 |
| /2013・2015 talk/show（個別トーク） | 0.86〜0.88（動的部品の除去による軽微差） |
| /2011/ トップ、/2011 news | 0.75〜0.79（後述の差あり） |

- 大半のページで本文は一致。相違は主に静的化に伴う意図的変更（jQuery 等の除去、
  埋め込みの https 化、コメント数など動的ウィジェットの消失）。
- **2011 年が最も弱い**: トップのニュース一覧が旧と異なり、ニュース記事のスラッグ（URL）が
  改名されている。内容の多くは別スラッグで存在するが、一部は取得不可の可能性（第4節）。

## 3. 差分の分類（現行で 404 の旧 URL 221 件）

| 分類 | 件数 | 判定 |
|---|---:|---|
| 孤立 URL（応募/不採択トーク・メンバー個別ページ、直リンクのみ） | 152 | 旧に実在。現行の一覧からはリンクされておらず、直リンクのみ到達不可 |
| 現行ページからリンクあり→リンク切れ | 15 | **要対応**（2013 スピーカー個別 13、2012 メンバー 1、2013 イベント 1） |
| editorial（2010/2011 のニュース等）URL 変更または欠落 | 15 | 一部は改名、一部は欠落の可能性（**要確認**） |
| URL 変更・内容は別パスに存在（`/2010/info/*`→`/2010/news/*`） | 14 | 許容（同一内容が取得可能） |
| 動的機能の廃止（login / order / subscribe / ticket / input 等） | 14 | 想定内（README 記載どおり動的処理は廃止） |
| 要確認（2010/info/、2010 talks の大文字 UUID ×3） | 4 | 軽微、**要確認** |
| 言語別 index（/2015/en/、/2015/ja/、/2011/en/） | 3 | 欠落の可能性（**要確認**） |
| individual_sponsors（2013、2014） | 2 | 欠落の可能性（2015 は存在）（**要確認**） |
| 動的ナビ（/2013/event/list） | 1 | 要確認 |
| 意図的な 404（/2013/talk/schedule、D-13） | 1 | 意図的（コミット S0-6b で旧どおり 404 化） |

孤立 URL 152 件の大半は 2015 年（talk 89・member 44）と 2013 年（talk 7）。
サンプル確認では実在するトーク応募ページ（例: 「perl/go での開発の比較」）で、現行の
採択トーク一覧（約 90 件）には含まれない。会期当時の応募/不採択ページと推測されるが、
旧サーバーに現存するかは未確認。

## 4. 実質的に要対応と考えられる差分

1. **2013 年のスピーカー個別ページ（`/2013/member/show/<UUID>`）が全欠落。**
   旧に 15 件存在し、うち 13 件が現行の 2013 トーク一覧・スケジュール・トーク詳細から
   リンクされているため **リンク切れ** になっている。2012・2014・2015 にはメンバーページが
   あるため 2013 のみ欠落しており、取りこぼしの可能性が高い。
   （なお PR #19/#25 の「マイページ→404」は個人のマイページ削除であり、スピーカー個別
   ページの意図的削除ではない点に注意。）

2. **2010/2011 のニュース記事の一部が取得不可またはスラッグ変更。**
   - 2011 news は旧 31 件に対し現行 22 件。`yapcasia-2011-call-for-papers`、
     `yapcasia-2011-sponsor`、`yapcasia-special`、`yapcasia-volunteer` 等は現行に該当スラッグが無い。
     一部は別スラッグ（例: special-guests.html）で内容が存在する可能性があり、記事単位の
     突き合わせが必要。
   - 2011 トップのニュース一覧が旧と食い違う（スナップショット時点差の可能性）。

3. **2010 トップからのリンク切れ。** `/2010/tickets.html`、`/2010/tickets_en.html`、
   `/2010/cheatsheet.html`、`/2010/info/yapcasia-2010.html`、`/2010/info/yapcasia-tokyo-2010-lt.html`
   は 2010/index.html からリンクされているが 404。一部は `/2010/news/` 配下に同名内容が
   存在（許容）だが、リンク先は旧 URL のままのものがある。

4. **individual_sponsors（2013・2014）と言語別 index（/2015/en/, /2015/ja/, /2011/en/）が 404。**
   2015 の individual_sponsors は存在するため、他年も本来存在した可能性。要確認。

5. **孤立トーク/メンバーページ（約 150 件）。** 直リンクでのみ到達する応募/不採択ページ。
   保存対象とするかは方針判断。現行ナビゲーションからは参照されないため通常閲覧に影響は無い。

---

## 5. 補足

- 動的エンドポイント（ログイン、注文、購読、チケット購入フォーム等）の 404 は
  README（「動的処理だった箇所は無くなっています」）どおりで問題なし。
- `/2013/talk/schedule`（クエリ無し）の 404 はコミット S0-6b（D-13）で旧サーバーの挙動に
  合わせた意図的なもの。
- 恒久リダイレクト 12 件（例: `/YYYY/photos` → 30d.jp のアルバム、`/2012/talk`→`/2012/talk/`）は
  正常に有効な宛先へ転送される。

`url-gaps.csv` に 221 件すべての URL・年・分類・（内容が別パスにある場合の）移動先・判定を収録。
